# 👻 Hollow Knight Tracker - Rastreador de Progresso
## Hollow Knight Tracker - Progress tracker

**[PT]** Este repositório apresenta meu primeiro projeto prático desenvolvido em Python, um rastreador de progresso para o jogo Hollow Knight.
Se trata de um programa baseado em CLI, onde o usuário informa as conquistas que ele já obteve (habilidades, magias, amuletos, etc) e descobre o seu percentual atual de conclusão do jogo.
Além disso o usuário também pode verificar o percentual de conteúdo restante, e o que falta ele atingir os 112% (percentual próprio do jogo) de conclusão.

**[EN]** This repository presents my first practical project developed in Python, a progress tracker for Hollow Knight.
It is a program based on CLI, where the user inform their obtained achievements (skills, spells, charms) and find out their actual game completion percentage.
Furthermore, the user also can verify the remaining content percentage, and what left for achieve the 112% (the game specific percentage)
