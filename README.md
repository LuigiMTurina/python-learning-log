# 🌱 Jornada em Python — Diário de Aprendizado
## Python Journey — Learning Log

**[PT]** Este repositório reúne os projetos práticos que venho construindo enquanto aprendo Python — do zero, com o objetivo de sair da teoria e sujar as mãos com código. Cada pasta numerada é um projeto independente e completo, com seu próprio README detalhando o que foi feito, as decisões tomadas e as limitações conhecidas.

Um princípio guia esse repositório: os projetos são publicados como estão, incluindo bugs e escolhas imperfeitas, porque o objetivo aqui não é uma vitrine de resultados polidos — é um registro honesto de evolução. Quando um projeto é corrigido ou expandido, isso fica documentado no histórico de commits e tags do próprio repositório, em vez de reescrito silenciosamente, e as melhorias e os erros identificados podem ser encontrados na aba de issues.

**[EN]** This repository collects the hands-on projects I've been building while learning Python — from scratch, aiming to move past theory and actually get code working. Each numbered folder is an independent, complete project, with its own README detailing what was built, the decisions made, and known limitations.

One guiding principle here: projects are published as they are, bugs and imperfect choices included, because the goal isn't a showcase of polished results — it's an honest record of growth. When a project is later fixed or expanded, that's documented through the repository's own commit history and tags, rather than silently rewritten, and the improves and identified errors can be found on the issues section.
